# Hello World

欢迎来到我的个人网站！

这是我使用 Next.js 和 Tailwind CSS 构建的作品集网站。网站采用了代码编辑器风格的设计，灵感来自 VS Code。

## 技术栈

- **Next.js** - React 框架
- **TypeScript** - 类型安全
- **Tailwind CSS** - 样式
- **Markdown** - 内容管理

## 功能特性

- 响应式设计
- 暗黑主题
- 代码高亮
- 博客系统
- 项目展示

感谢你的访问！
