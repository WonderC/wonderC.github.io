# 图片资源说明

本文件夹包含网站所需的所有图片资源。

## 文件夹结构

```
images/
├── carousel/     # 轮播图背景图片（3张，1920x1080）
│   ├── slide1.jpg
│   ├── slide2.jpg
│   └── slide3.jpg
├── products/     # 产品展示图片（6张，400x300）
│   ├── oil.jpg           # 食用油
│   ├── rice.jpg          # 大米
│   ├── flour.jpg         # 面粉
│   ├── seasoning.jpg     # 调味品
│   ├── tech.jpg          # 油脂科技
│   └── food.jpg          # 米面食品
└── news/         # 新闻中心图片（3张，600x400）
    ├── news1.jpg
    ├── news2.jpg
    └── news3.jpg
```

## 图片规格

### 轮播图（carousel/）
- **尺寸**：1920x1080 像素
- **格式**：JPG
- **用途**：首页轮播图背景
- **命名规则**：slide1.jpg, slide2.jpg, slide3.jpg

### 产品展示（products/）
- **尺寸**：400x300 像素
- **格式**：JPG
- **用途**：产品与服务展示卡片
- **命名规则**：对应产品英文名称.jpg

### 新闻中心（news/）
- **尺寸**：600x400 像素
- **格式**：JPG
- **用途**：新闻中心卡片
- **命名规则**：news1.jpg, news2.jpg, news3.jpg

## 替换图片

如果要替换图片，请遵循以下规则：

1. 保持相同的文件名（如 slide1.jpg）
2. 推荐尺寸参考上述规格
3. 使用 JPG 格式以获得更好的兼容性和压缩比
4. 图片文件大小建议控制在 500KB 以内以保证加载速度

## 自定义占位图片

当前使用的是自动生成的占位图片。如果您想替换为真实图片：

1. 准备好图片资源
2. 保持相同的文件名
3. 将图片复制到对应文件夹中替换现有文件
4. 刷新网页即可看到效果

## 注意事项

- ⚠️ 部署时必须包含整个 `images/` 文件夹
- ⚠️ 不要更改文件夹名称（carousel、products、news）
- ⚠️ 保持相对路径 `images/` 不变
- 💡 建议使用 WebP 格式以进一步优化加载速度（需要相应更新 HTML 中的图片引用）
